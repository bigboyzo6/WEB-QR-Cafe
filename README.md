# WEB-QR-Cafe

Website pemesanan kafe berbasis QR Code yang dirancang untuk memudahkan pelanggan dalam melihat menu, melakukan kustomisasi pesanan, memilih meja, hingga konfirmasi pesanan secara mandiri.

## 📱 Fitur Utama & Halaman

* Welcome Page (welcome.html) — Halaman penyambutan pengguna.
* Verifikasi Login (loginverification.html) — Autentikasi/verifikasi data diri dan nomor meja pengguna.
* Denah Meja & Stopkontak (seatoutletmap.html) — Peta denah kafe interaktif untuk melihat ketersediaan meja dan lokasi stopkontak.
* Katalog Menu (menucatalog.html) — Daftar menu lengkap beserta filter kategori (Vegetarian, Dairy-Free, dll).
* Kustomisasi Produk (productcostumization.html) — Opsi penyesuaian porsi, varian susu, dan catatan khusus.
* Ringkasan Ringkas & Ringkasan Pesanan (checkout.html) — Ringkasan item pesanan beserta klaim kode promo.
* Konfirmasi Pesanan (orderconfirm.html) — Bukti struk pesanan beserta estimasi waktu penyiapan.

## 🛠️ Teknologi yang Digunakan

* HTML5 (Semantik & Bebas Error W3C Validator)
* CSS3 (Kustom layout & gaya responsif)
* SVG & Vector Graphics (Ikonografi ringan)
